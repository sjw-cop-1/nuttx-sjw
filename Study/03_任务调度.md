# 03 任务调度

NuttX 的调度核心位于 `sched/`，是理解整个内核的钥匙。

## 1. 任务模型

- **任务 (task)**：独立地址空间的进程（类似 Linux 的 process，但没有 fork，用 `task_create`/`posix_spawn`）
- **线程 (pthread)**：同一地址空间内的执行流（`sched/pthread/`）
- 在内核内部，任务和线程统一用 **TCB (Task Control Block)** 表示，靠标志位区分

关键文件：
- `include/nuttx/sched.h` —— TCB 定义、任务状态枚举
- `sched/task/` —— 任务创建/退出/等待
- `sched/pthread/` —— POSIX 线程

## 2. TCB —— 一切的核心

`struct tcb_s`（include/nuttx/sched.h）关键字段：

```c
struct tcb_s
{
  /* 链表节点：所有 TCB 挂在各种队列上 */
  FAR struct tcb_s *flink;      // 双向链表前向指针
  FAR struct tcb_s *blink;      // 双向链表后向指针

  pid_t  pid;                   // 进程 ID
  uint8_t sched_priority;       // 当前调度优先级（可能被临时提升）
  uint8_t init_priority;        // 初始优先级
  tstate_t task_state;          // 任务状态（见下）
  uint8_t flags;                // TCB_FLAG_*（TASK_FLAG、PTHREAD_FLAG 等）

  FAR uint32_t *stack_ptr;      // 栈指针
  size_t stack_size;            // 栈大小
  FAR uint8_t *stack_alloc_ptr; // 栈起始地址

  /* 调度器私有字段（sched/sched/sched.h）：
     FAR struct tcb_s **waitobj;   // 等待对象（信号量等）
     ...
  */
};
```

实际定义比这大得多（包含 CPU 寄存器保存区、信号、定时器、文件描述符表、TLS 等），
建议先看字段注释较多的部分，如 `priority`、`task_state`、`flink/blink`。

## 3. 任务状态与就绪队列

任务状态（`tstate_t`，include/nuttx/sched.h）：

```
TSTATE_TASK_INVALID      无效
TSTATE_TASK_PENDING      等待 CPU（被锁调度器阻塞，SMP 用）
TSTATE_TASK_READYTORUN   就绪（等待获得 CPU）
TSTATE_TASK_RUNNING      运行中
TSTATE_TASK_INACTIVE     未激活（已创建未就绪）
TSTATE_TASK_WAITEXIT     等待子任务退出（waitpid）
TSTATE_TASK_WAITSIG      等待信号
TSTATE_TASK_MQNOTEMPTY   等待消息队列非空
TSTATE_TASK_MQNOTFULL    等待消息队列有空间
TSTATE_TASK_WAITSEM      等待信号量
TSTATE_TASK_WAITDOG      等待看门狗定时器（延时/超时）
```

就绪队列（`sched/sched/`）：
- `g_readytorun`：全局就绪队列（数组，每优先级一个链表头），**队首就是当前运行任务**
- `g_tasklisttable[]`：所有任务链表的索引表（按状态分类）
- SMP 下每个 CPU 还有自己的 `g_cpulist`/本地就绪队列

## 4. 调度算法

### 4.1 优先级抢占 (Priority-based preemptive)

- 每个任务有优先级（0~255，数值越大优先级越高，`CONFIG_SCHED_PRIORITY_MAX` 可配）
- 高优先级任务就绪 → 立即抢占低优先级任务（通过 `nxsched_addreadytorun()` 触发）
- 关键函数：
  - `nxsched_addreadytorun()` —— 任务进入就绪态（sched/sched/sched_addreadytorun.c）
  - `nxsched_removereadytorun()` —— 任务离开就绪态（sched_removereadytorun.c）
  - `nxsched_mergepending()` —— 合并挂起任务（sched_mergepending.c）
  - `sched_roundrobin()` —— 时间片轮转触发（sched_roundrobin.c）

### 4.2 时间片轮转 (Round-robin)

- 同优先级多个任务：每个任务运行 `CONFIG_RR_INTERVAL` 个 tick 后切换
- 由 tick 中断调用 `sched_processtick()`（sched_processtick.c）→ `sched_roundrobin()` 实现

### 4.3 其他调度策略

- `SCHED_SPORADIC`： sporadic 调度（sched_sporadic.c），有预算/补给的调度
- `SCHED_FIFO`：无时间片的先入先出
- `SCHED_BATCH` / `SCHED_OTHER`：默认策略
- 通过 `sched_setscheduler()` / `pthread_setschedparam()` 设置

### 4.4 调度器锁 (sched_lock)

- `sched_lock()` / `sched_unlock()`：关闭/开启抢占（sched_lock.c、sched_unlock.c）
- 锁定时新就绪的高优先级任务进入 `TSTATE_TASK_PENDING` 挂起队列，解锁后合并
- 这是 NuttX 实现临界区的主要手段之一（配合 `sched_lockcount` 计数）

## 5. 上下文切换

- 主动切换：任务调用阻塞 API（如 `nxsem_wait`）→ `up_switch_context()`（架构函数）
- 被动切换：tick 中断或外部中断 → 中断返回路径检查是否有更高优先级任务 → 切换
- 架构实现：`arch/<arch>/src/common/` 下的 `up_switchcontext.c`、`arm_switchcontext.c` 等
- 首次切换：`arm_task_start.c`（新任务栈上预置好"虚假的返回地址"，恢复现场即跳到任务入口）

## 6. 任务创建与退出

- `task_create()` / `nxtask_create()`（sched/task/task_create.c）：
  1. 分配 TCB + 栈（`up_create_stack`）
  2. 初始化 TCB（`nxtask_setup_scheduler`、`nxtask_setup_stackandtcb`）
  3. 把入口地址和参数压入栈（`nxtask_start` 跳板）
  4. `nxtask_activate()` 加入就绪队列（若可抢占则立即切换）
- 退出：`task_exit()` / `exit()` → `nxtask_exit()` → 释放 TCB 栈，唤醒等待者
- `waitpid()`（sched/sched/sched_waitpid.c）等待子任务退出

## 7. SMP 多核调度

- `sched/sched/sched_smp.c`：CPU 间负载均衡、任务迁移
- 每个 CPU 一个 idle 任务；`CONFIG_SMP_NCPUS` 控制核数
- `sched_setaffinity()` 设置任务亲和性
- 自旋锁 `spin_lock`（include/nuttx/spinlock.h）保护多核临界区

## 8. 信号量与优先级反转

信号量实现在 `sched/semaphore/`，最值得读的是优先级继承：

- `sem_holder.c`：跟踪每个信号量的持有者
- 高优先级任务等一个被低优先级任务持有的信号量时，**临时提升持有者的优先级**（`nxsched_setpriority`）
- 释放时恢复（`sem_post` 中处理）
- 相关配置：`CONFIG_PRIORITY_INHERITANCE`

## 9. 建议阅读顺序

1. `include/nuttx/sched.h` —— TCB 与状态定义（先扫一遍字段）
2. `sched/sched/sched.h` —— 调度器私有结构（g_readytorun 等）
3. `sched/init/nx_start.c` —— 看 idle 任务怎么建（调度器起点）
4. `sched/task/task_create.c` —— 任务创建全流程
5. `sched/sched/sched_addreadytorun.c` + `sched_removereadytorun.c` —— 调度的核心
6. `sched/semaphore/sem_wait.c` + `sem_post.c` —— 阻塞/唤醒的典型实现
7. `sched/sched/sched_roundrobin.c` + `sched_processtick.c` —— 时间片
8. 有余力再看 `sched/sched/sched_smp.c`（SMP）

## 10. 动手实验

改 `boards/<你的板子>/configs/<config>/defconfig` 或 menuconfig：
- `CONFIG_RR_INTERVAL`：改小看时间片切换频率
- `CONFIG_PRIORITY_INHERITANCE`：开关优先级继承
- `CONFIG_SCHED_CRITMONITOR`：开关键区监控，打印调度延迟
