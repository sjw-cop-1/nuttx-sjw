# 09 时钟、定时器、信号与信号量

本文覆盖 RTOS 的时间与同步基础设施：时钟（clock）、看门狗定时器（wdog）、
POSIX 定时器（timer）、信号（signal）、信号量（semaphore）、消息队列（mqueue）。
这些都在 `sched/` 目录下，是任务调度之外最重要的内核机制。

## 1. 系统时钟（sched/clock/）

### 1.1 基本概念

- **tick**：系统时钟节拍，由硬件定时器中断产生（`CONFIG_USEC_PER_TICK`，默认 10000us = 10ms）
- `TICK_PER_SEC`（include/nuttx/clock.h）：每秒 tick 数
- 系统时间用 tick 计数（`clock_systime_ticks()`），可换算成 timespec

### 1.2 关键文件

- `clock_initialize.c` —— 时钟子系统初始化
- `clock_gettime.c` / `clock_settime.c` —— POSIX 时钟接口（CLOCK_REALTIME / MONOTONIC）
- `clock_systime_ticks.c` —— 读取系统 tick 计数
- `clock_delay.c` —— 忙等待延时（`up_mdelay` 等）
- `clock_timekeeping.c` —— 纳秒级时间维护（`CONFIG_CLOCK_TIMEKEEPING`）
- `clock_notifier.c` —— 时钟事件通知器（时钟变化时通知注册者，如 RTC 同步）
- `clock_perf.c` —— 性能计数（`CONFIG_CLOCK_PERF`，读 CPU 周期计数器）

### 1.3 tick 中断如何驱动内核

```
硬件定时器中断
  └─> 架构 tick 处理: up_timer_initialize() 注册的回调
        └─> sched/sched/sched_processtick.c: nxsched_process_timeslice()
              ├─ 时间片到 → sched_roundrobin() 轮转
              ├─ 唤醒到期的 wdog（延时/超时）
              └─ 触发到期定时器
```

## 2. 看门狗定时器 wdog（sched/wdog/）

NuttX 的 wdog 不是硬件看门狗，而是**内核延时/超时机制**（类似 FreeRTOS 的软件定时器）：

- `wd_start()` —— 启动一个延时回调（在指定 tick 数后调用回调函数）
- `wd_cancel()` —— 取消
- `wd_gettime()` —— 查询剩余时间
- 用途：
  - `sleep()`/`usleep()`/`nanosleep()` 的实现基础
  - `sem_timedwait()` 的超时
  - 网络协议超时重传（TCP 定时器）
  - 驱动轮询延时

实现要点：
- wdog 挂在 TCB 上（`tcb->timercb` 等字段），到期后由 tick 中断处理
- 回调在中断上下文执行，**必须简短**，不能阻塞

## 3. POSIX 定时器（sched/timer/）

- `timer_create()` / `timer_settime()` / `timer_gettime()` / `timer_delete()` / `timer_getoverrun()`
- 定时器到期发送信号（SIGEV_SIGNAL / SIGEV_THREAD / SIGEV_NONE）
- 基于 wdog 实现，信号投递机制在 sched/signal/

## 4. 信号 signal（sched/signal/）

### 4.1 数据结构

- `struct sigactq`：sigaction 动作表（每任务一份）
- `struct sigpendq`：挂起的信号队列
- 信号在 TCB 里有对应字段（`sigpendactionq`、`sigpendq`、`sigprocmask` 等）

### 4.2 关键流程

- `sig_kill.c` / `sig_tgkill.c` —— 发送信号：
  1. 目标任务查找信号动作（sig_findaction.c）
  2. 若信号被屏蔽 → 挂入挂起队列
  3. 若未屏蔽 → 唤醒目标任务（若在等待信号）
- `sig_deliver.c` —— 信号投递：目标任务被调度后，在**返回用户态前**执行信号处理函数（类似 Linux 的 signal frame）
- `sig_dispatch.c` —— 分发到目标任务
- `sig_action.c` —— sigaction 系统调用实现
- `sig_nanosleep.c` / `sig_sleep.c` —— sleep 系列（内部用 wdog + 信号等待）

要点：信号处理函数在哪个上下文执行？
- 目标任务被唤醒后，tick 中断/切换路径检查 `sigpendactionq`，若该任务有挂起信号且未被屏蔽，
  在 `up_switchcontext` 返回前把信号处理函数"塞进"任务栈（构造信号帧），任务恢复运行时先执行 handler，再继续原流程。

## 5. 信号量 semaphore（sched/semaphore/）

### 5.1 数据结构

```c
struct sem_s        // include/nuttx/semaphore.h
{
  int16_t semcount;         // 当前计数
  /* 等待队列（优先级排序） */
  FAR struct tcb_s *sem_waitlist;  // 等在这个信号量上的任务链表
  /* 优先级继承持有者信息（CONFIG_PRIORITY_INHERITANCE） */
  FAR struct tcb_s *sem_holder;    // 当前持有者
};
```

### 5.2 关键流程

- `sem_wait.c`（nxsem_wait）：
  1. `semcount > 0`？→ 减一返回
  2. 否则：任务状态改为 `TSTATE_TASK_WAITSEM`，加入等待队列（按优先级排序），
     触发调度（`nxsched_addreadytorun` 里处理），CPU 让给其他任务
  3. 优先级继承：若持有者优先级低于等待者 → 提升持有者优先级（sem_holder.c）
- `sem_post.c`（nxsem_post）：
  1. `semcount++`
  2. 若等待队列非空 → 唤醒队首（最高优先级）任务，把计数交给它
  3. 若持有者优先级被提升过 → 恢复原优先级
- `sem_timedwait.c` / `sem_tickwait.c` —— 带超时等待（wdog + 信号量组合）
- `sem_setprotocol.c` —— 设置协议（PRIO_INHERIT / PRIO_PROTECT / NONE）
- `sem_rw.c` —— 读写锁

### 5.3 中断安全

- `nxsem_wait` 不可在中断上下文调用（会调度）
- 中断中唤醒用 `nxsem_post` 的特殊变体（如 `sem_post` 在中断里只做"标记+延迟处理"，或使用 `nxsem_wait_uninterruptible` 语义）
- 驱动的 ISR 里通常用 `sem_post` 唤醒读线程（post 在中断上下文是安全的）

## 6. 消息队列 mqueue（sched/mqueue/）

- POSIX 消息队列：`mq_open` / `mq_send` / `mq_receive` / `mq_notify` / `mq_close` / `mq_unlink`
- 数据结构：`struct mqueue_inode_s`（消息队列本体，含 `mq_msgq` 消息链表、等待发送/接收的任务队列）
- 消息：`struct mqueue_msg_s`（大小 + 优先级 + 数据）
- 关键文件：
  - `mq_initialize.c` —— 消息队列模块初始化（预分配消息池）
  - `mq_send.c` / `mq_sndinternal.c` —— 发送（按优先级插入消息链表，唤醒接收者）
  - `mq_receive.c` / `mq_rcvinternal.c` —— 接收（无消息则阻塞 TSTATE_TASK_MQNOTEMPTY）
  - `mq_notify.c` —— 异步通知（信号或回调）
  - `mq_waitirq.c` —— 等待被信号打断的处理
- 消息队列挂载在 VFS 上：`/mqueue` 命名空间（`mq_open("/myq")`），由 `fs/mqueue/` 提供文件系统视图

## 7. 条件变量与互斥锁

- `sched/pthread/pthread_mutex*.c` —— pthread 互斥锁（内部用信号量实现）
- `sched/pthread/pthread_cond*.c` —— 条件变量（内部也是信号量 + 时钟等待）

1. `sched/semaphore/sem_wait.c` + `sem_post.c` —— 信号量核心（优先）

3. `sched/clock/clock_initialize.c` + `clock_systime_ticks.c` —— 时间基础

5. `sched/mqueue/mq_send.c` + `mq_receive.c` —— 消息队列

7. `sched/timer/timer_settime.c` —— POSIX 定时器如何用 wdog+信号组合
